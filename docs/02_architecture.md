# Общая архитектура

## Основная идея

Проект разделяется на независимые уровни:

- Application Layer — пользовательское приложение
- Core — универсальная логика конструктора персонажей
- Game Systems — описания конкретных НРИ
- Content — данные игровых систем и пользовательские расширения

Главный принцип:
Добавление новой игровой системы не должно требовать изменения Core.

---

## Какие основные подсистемы существуют?

### Core

Отвечает за:
- управление персонажами;
- хранение состояния персонажа;
- применение правил;
- вычисление эффектов;
- версионирование состояния.

Не знает:
- D&D;
- GURPS;
- конкретные характеристики;
- конкретные классы/расы/уровни.

---

### Game System

Отвечает за:
- описание конкретной НРИ;
- предоставление контента;
- определение доступных правил;
- определение структуры персонажа.

Примеры:
- D&D 5e;
- GURPS 4e.

Не содержит:
- пользовательскую логику приложения;
- UI;
- хранение аккаунтов.

---

### Content Layer

Отвечает за:
- хранение игровых сущностей;
- описание доступных элементов выбора;
- хранение официального и пользовательского контента.

Примеры:
- расы;
- классы;
- предметы;
- заклинания;
- преимущества.

---

### Application Layer

Отвечает за:
- взаимодействие пользователя с системой;
- авторизацию;
- интерфейс;
- управление пользовательскими действиями.
