# Roadmap

Проект развивается итеративно.

Каждый следующий этап должен приносить самостоятельную ценность и не требовать полной переработки предыдущих решений.

---

# MVP

Цель MVP — создать минимально работоспособный конструктор персонажей для одной игровой системы.

## Обязательно должно работать

- подключение игровой системы;
- загрузка контента;
- создание персонажа;
- изменение характеристик;
- применение правил;
- автоматический пересчет параметров;
- сохранение и загрузка персонажа;
- базовая локализация.

## Минимально достаточные функции

Пользователь должен иметь возможность создать полностью корректного персонажа без ручных вычислений.

---

# После MVP

## Поддержка нескольких игровых систем

- независимое подключение систем;
- выбор системы при создании персонажа;
- независимые наборы контента.

## Кампании

- хранение нескольких персонажей;
- настройки кампании;
- ограничения и домашние правила на уровне кампании.

## Пользовательский контент

- создание собственного контента;
- редактирование существующего;
- подключение пользовательских пакетов;
- импорт и экспорт домашних правил.

## Импорт и экспорт

Поддержка:

- экспорта персонажей;
- экспорта контента;
- резервного копирования;
- обмена между пользователями.

---

# Общий каталог

Возможность публикации:

- игровых систем;
- домашних правил;
- пакетов контента;
- шаблонов персонажей.

Каталог должен поддерживать версии и обновления.

---

# API

Публичный API для:

- создания альтернативных клиентов;
- автоматизации;
- интеграции с другими сервисами;
- разработки сторонних инструментов.

---

# Мобильная версия

Полноценный мобильный клиент с возможностью:

- просмотра персонажей;
- редактирования;
- работы без подключения к сети;
- синхронизации после подключения.

---

# Плагины

Поддержка расширений без изменения ядра.

Плагины могут добавлять:

- игровые системы;
- новые типы контента;
- способы импорта и экспорта;
- интеграции;
- пользовательские инструменты;
- элементы интерфейса.

---

# Долгосрочная цель

Создать универсальную платформу для работы с настольными ролевыми играми, позволяющую:

- поддерживать различные игровые системы;
- использовать официальный и пользовательский контент;
- создавать собственные расширения;
- развивать экосистему независимо от ядра проекта.
